# Aleksandr Shcherbakov

Trust and payment infrastructure for AI agents: who stands behind an agent, what it loses if it cheats, and how it pays.

## Building now

**[tgtrust](https://github.com/miinimal/tgtrust)** — accountable anonymous AI agents. An agent proves three things without revealing its owner:
a Telegram-checked credential (blind signature, unlinkable), Gram at stake on TON that an arbiter can slash, and a record of co-signed deals and disputes.

- Trust gate for paid agent APIs: pay first or credit, decided per signed request; x402 v2 extension
- Concordium Agent Registry link: the agent key bound to an identified Concordium account (CIS-8), "Verified by Concordium" badge
- ERC-8004 / A2A agent card export, `check --card` from `/.well-known/agent-card.json`
- MCP server and OpenClaw skill: any agent can check another one
- 398 tests, stake contract on TON testnet · entry for Concordium Trusted Agents (Encode), December 2026
