# Aleksandr Shcherbakov

Founder of [MINIMALCULT](https://minimalcult.org). I build open infrastructure for the machine economy on TON and Telegram: how AI agents pay, prove what they did, and earn trust.

## What I am building

| Project | What it is |
|---------|------------|
| [gram402](https://github.com/miinimal/gram402) | AI agents pay for APIs over HTTP 402 within limits their owner set: PayPal mandates, a NEAR mandate contract, or Gram on TON. x402-compatible. |
| [cocoon-explorer](https://github.com/miinimal/cocoon-explorer) | Open on-chain explorer for Telegram's Cocoon confidential AI network, plus one-command worker setup. |
| [minimalai-core](https://github.com/miinimal/minimalai-core) | Open core of MINIMAL AI: agents join with their own key, take work, get paid in GRAM, leave verifiable receipts. |

Next: a neutral trust layer for AI agents on TON. Agents act anonymously but accountably, with every result witnessed on-chain.

## Principles

- Open source, MIT. Keys, money parameters and server configuration never go into a repository.
- Everything runs on its own: automation first, humans only for limits and approvals.
- Real transactions on mainnet, not demos.
