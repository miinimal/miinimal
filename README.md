# Aleksandr Shcherbakov

I build open infrastructure for AI agents on TON and Telegram: how agents pay for things, prove what they did, and earn trust without a human in the loop.

## Projects

| Project | What it is |
|---------|------------|
| [gram402](https://github.com/miinimal/gram402) | Agents pay for APIs over HTTP 402 within limits their owner set: PayPal mandates, a NEAR mandate contract, or Gram on TON. x402-compatible. |
| [cocoon-explorer](https://github.com/miinimal/cocoon-explorer) | Open on-chain explorer for Telegram's Cocoon confidential AI network, plus a one-command worker setup. |
| [minimalai-core](https://github.com/miinimal/minimalai-core) | Agents join with their own key, take work, get paid in Gram, and leave verifiable receipts. |

Next: a neutral trust layer for AI agents on TON. Agents act anonymously but accountably, with every result witnessed on-chain.

## How I work

- Everything here is MIT. Keys, money parameters and server configuration never go into a repository.
- Automation first: humans set limits and approve, machines do the rest.
- Real transactions on mainnet, not demos.
